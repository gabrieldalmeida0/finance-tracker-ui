# Protótipo de Controle Financeiro

Protótipo de interface criado no Figma para apoiar a organização de receitas, despesas e saldo pessoal.

## Objetivo

Praticar prototipação de interfaces, organização visual das informações e criação de uma experiência simples para acompanhamento financeiro.

## Ferramenta

- Figma
